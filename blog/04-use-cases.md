## 一、先看它和「语音助手」的本质区别

普通语音助手只有「听」和「说」。而具身数字人多了一条关键能力：**表达**——说话时的口型、表情、手势、身体动作，都是实时生成的。

这意味着同样一句「欢迎光临」，它可以是：

- 微笑 + 欠身 + 伸手（导购场景）
- 挥手 + 兴奋语气（直播开场）
- 严肃 + 点头（新闻播报）

**「会表达」是它能进入线下和商业场景的底层原因。** 文字、语音解决「信息」，表情和动作解决「信任和氛围」。

## 二、六大落地场景

### 1. 直播带货 / 短视频口播

数字人主播 7×24 在线，不喊累、不翻车。配大模型后能根据商品脚本自动讲解、互动。

**Demo 玩法对照**：「流式播报」+「自动演示」——把商品话术切成脚本，数字人一条条讲，字幕、动作、表情全程配合。

### 2. 新闻播报 / 资讯类

标准化、高频的内容最适合。SSML 控制语气和动作，配合字幕，就是一套轻量「虚拟主播台」。

### 3. 门店导购 / 品牌 IP

线下大屏摆一个品牌数字人，顾客走近它就打招呼、介绍产品。**离线模式不消耗积分**，适合长时间待机。

**台词改写示例**（把「跳舞」换成导购动作即可）：

```xml
<speak>
  <ue4event><type>ka</type><data><action_semantic>Hello</action_semantic></data></ue4event>
  欢迎光临！左边是我们的新品区，右手边有今日特惠，需要我带你看看吗？
</speak>
```

### 4. 展厅 / 发布会讲解

数字人讲解员配合大屏/投影，开场致辞、产品讲解、答疑一条龙。「开场秀」这个 Demo 就是为这类场景设计的。

### 5. 智能客服 / 前台

接大模型 + 语音识别，就是能「面对面」答疑的虚拟前台。配合 `onVoiceStateChange` 管理对话节奏。

### 6. 教育 / 陪伴 / 培训

数字人讲师或陪伴角色，情感表达让它比冷冰冰的语音更有温度。

## 四、不止是屏幕：一套 SDK 全终端

这一点值得单独说。官方强调的「一套 SDK 同步适配**屏幕、人形机器人、AR/VR 眼镜**」，意味着同一套 `speak()` 逻辑，可以从网页搬到机器人身上——机器人不再是「播放录音」，而是**实时生成动作和口型**的具身表达。

对开发者来说，这意味着：

1. **一次开发，多端复用**：屏幕端的接入代码，机器人端能复用；
2. **统一的技术栈**：不用为每个终端单独学一套；
3. **规模化部署**：官方标称千万级并发、百元芯片轻量部署，给线下/物联网场景留了余量。

## 五、怎么选场景、怎么起步

1. **从内容型场景起步**（播报、讲解）：标准、可控，最容易出效果；
2. **再上交互型场景**（客服、导购）：接大模型 + 语音识别，验证体验闭环；
3. **最后做品牌化定制**：定制数字人形象、动作库，形成差异化 IP。

需要定制形象或深度集成的，官方也提供商务合作渠道（官网 https://xingyun3d.com/ 可联系）。
